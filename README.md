# EduBench — Сравнение нейросетей для образования

Одностраничный бенчмарк: сравнение нейросетей по генерации образовательного контента на 8 кейсах. Проект помогает педагогам выбрать подходящие инструменты и использовать готовые промпты.

## Структура проекта

```
├── index.html     — главная, бенчмарк, нейросети
├── prompts.html   — промпты для педагогов с поиском и фильтрами
├── cases.html     — кейсы: анализ данных, звука, разработка приложений
├── script.js      — данные (MODELS, CASES, PROMPTS) и логика рендеринга
├── style.css      — общие стили
├── favicon.svg    — иконка сайта
├── ex/            — примеры файлов (ex_1.xlsx, ex_2.xlsx, ex_3.mp3, ex_4.doc)
└── case/          — результаты бенчмарка по кейсам и моделям
    ├── 1/ … 8/    — папки для каждого кейса
    └── */         — alice.html, deepseek.html, gigachat.html, mistral.html, qwen.html
```

## Локальный запуск

```bash
# Вариант 1: npx serve
npx serve .

# Вариант 2: Python
python -m http.server 8000
```

Затем откройте в браузере: `http://localhost:3000` (serve) или `http://localhost:8000` (Python).
