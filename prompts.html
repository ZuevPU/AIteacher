Промпты для педагогов: использование нейросетей в образовании

Нейросети — оперативный помощник учителя: сокращают время на подготовку занятий, расширяют спектр дидактических форматов и позволяют создавать адаптивные и творческие задания.

Что могут нейросети в школе

  • создавать задания и тесты
  • подбирать материалы под уровень класса
  • генерировать сценарии уроков и мероприятий
  • формировать творческие задания для креативных проектов
  • помогать в анализе текстов и документов
  • улучшать визуальное оформление материалов
1. Учебные задания и тесты
Физика
Создай 10 задач по физике для 9 класса по теме «Законы Ньютона» с тремя уровнями сложности.
Математика
Составь 5 задач по теме «Квадратные уравнения» для учеников с базовым уровнем подготовки.
Литература
Составь задание по литературе для 9 класса с анализом образов главных героев «Войны и мира».
История
Создай 20 вопросов по теме «Древняя Греция» для 5 класса с ответами.
2. Промпты по предметам
Математика — пропорции
Ты — учитель математики. Создай 10 задач для 7 класса по теме пропорции и проценты.
Требования: 3 задачи базовые; 5 задач среднего уровня; 2 задачи повышенной сложности; укажи ответы; избегай однотипных формулировок.
Физика — плотность
Создай 5 задач по физике для 8 класса по теме плотность вещества, в которых используются жизненные ситуации (кухонные измерения, объём воды, бытовые предметы). Добавь ответы.
Химия — растворы
Составь 12 задач по химии для 9 класса по теме массовая доля вещества в растворе.
Включи: 4 задачи на прямой расчёт; 4 задачи на приготовление раствора; 4 задачи на обратный расчёт (через массу раствора).
Биология — тест
Составь тест из 15 вопросов для 7 класса по теме кровеносная система человека.
5 — с вариантами ответов; 5 — на соответствие; 5 — открытых. Добавь ключи и краткие комментарии к правильным ответам.
История — аналитика
Составь аналитическое задание по теме Киевская Русь для 6 класса.
Требуется: мини-историческое сравнение (до 5 предложений); 3 вопроса на причинно-следственные связи; 1 творческое задание.
Английский — Past Continuous
Создай 10 заданий на тему Past Continuous:
4 предложения на дополнение; 3 задания на исправление ошибок; 3 диалоговых мини-задачи.
3. Творческие задания и проекты
Экология
Составь проектное задание по экологии для 5 класса: исследовать экологические проблемы школы и предложить решения.
Литература — письмо героя
Составь творческое задание: написать письмо от лица крестьянина времён Великой французской революции.
Биология — творческое
Придумай творческое задание для 5 класса: «Представьте, что вы клетка организма». Опиши функции, взаимодействие с другими клетками, «рабочий день клетки». Формат — мини-рассказ (8–10 предложений).
4. Работа с творческими задачами и креативом
Креативный редактор — 12 углов подачи
Ты — креативный редактор. Мне нужна не готовая публикация, а варианты для подачи.
Тема: [тема]. Аудитория: [аудитория]. Цель: [что должен сделать читатель].

Дай 12 «углов»:
4 практичных («сделай завтра»)
3 провокационных (но без токсичности)
3 через личную мини-историю
2 через метафору/образ

Для каждого: заголовок + 1 тезис + какой формат лучше (пост/письмо/скрипт/сторис)
Сценарный редактор — 3 структуры
Ты — сценарный редактор.
Сделай 3 разные структуры сценария по теме [тема] [длительность/формат].

Каждая структура:
хук (первые 10 секунд / первая фраза)
3–5 ключевых сцен/блоков (что происходит)
«поворот» (момент переосмысления)
финал (что зритель/слушатель должен унести)
2 места для живого примера из реальной жизни (без выдуманных фактов)

Не пиши финальный текст — только скелет и ритм.
Редактор — ломаем клише
Ты — редактор, который ломает клише на [тема].

Сделай 10 альтернативных подач/идей, используя разные оптики:
«контринтуитивно» (почему все делают неправильно)
«через ошибку/факап» (что обычно упускают)
«через аналогию» (неожиданный образ)
«через вопрос» (сократовский стиль)
«через чек-лист» (коротко и практично)

Для каждой: 1 заголовок + 2 ключевые мысли.

Запрет: штампы и общие слова. Не писать готовый текст.
5. Mind Map и кластеры
Mind Map по теме
Создай структурированную mind map по теме [тема] для [класс].
Требования: 1 центральный концепт; 4–6 ветвей; у каждой ветви — 3–5 подветвей; дай схему в виде иерархического списка.
Mind Map для ЕГЭ/ОГЭ
Создай mind map для подготовки к ЕГЭ/ОГЭ по [предмет]. Структура: основные темы экзамена; ключевые формулы/термины; типичные ошибки; тактика выполнения. Вывод в виде дерева.
Кластер для объяснения
Создай кластер для объяснения темы [тема]. В центре — ключевое понятие. Вокруг — 6 смысловых блоков: определения, свойства, примеры, исключения, практическое применение, контрольные вопросы.
6. Административно-организационные задачи
SMM — план продвижения
Ты — опытный SMM-специалист. Мы запускаем [программа] для [целевая аудитория]. Опиши пошаговый план продвижения: каналы, УТП, типы контента, график публикаций.
Письмо-приглашение
Ты — представитель оргкомитета. Напиши краткое мотивирующее приглашение для [аудитория] на конференцию [тема]. Укажи 3 выгоды.
Описание вакансии
Напиши подробное описание вакансии [название], включая обязанности и компетенции, связанные с [сфера].
7. Управление школой и стратегия
Стратегия развития
Сформируй стратегию развития школы на 1/3/5 лет. Учитывай: приоритеты образования РФ, результаты внутреннего мониторинга, кадровый состав, текущие риски, зоны роста, цифровые проекты, внеурочную деятельность, профильность, взаимодействие с сообществом. Представь стратегию в виде целей, KPI, шагов внедрения и ожидаемых эффектов.
План ВШК
Создай детализированный план внутришкольного контроля по направлениям: уроки, документация, воспитательная работа, внеурочная деятельность, цифровые инструменты, работа классных руководителей. Добавь инструменты оценки и формы вывода данных.
Коммуникация с родителями
Разработай план коммуникации с родительским сообществом на год: ключевые темы, каналы, частота, формы обратной связи, риски и способы их предупреждения.
